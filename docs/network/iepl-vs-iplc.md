物理光纤在真空与玻璃介质中的光速决定了跨境传输的延迟理论下限：

## 四、 专线架构与公网海底光缆晚高峰丢包物理成因

为什么同样连接境外服务器，公网海底光缆在晚上一定会丢包，而内网专线全天 0 丢包？
* **公网出口的共享排队机制**：公网国际出口（如中美、中日海缆）采用的是尽力而为（Best-Effort）的数据包转发策略。每当晚高峰数千万网民同时拉取境外视频、代码时，国际骨干路由器的数据包队列瞬间爆满，交换机芯片被迫将后续到达的数据包直接物理丢弃，导致丢包率飙升至 20%~40%；
* **IEPL 内网专线的时隙与波长独占**：IEPL 专线走的是跨国电信运营商在海底光纤中预先切分出来的独立时分复用（TDM）时隙或独立密集波分（DWDM）波长通道。专线通道在物理层上与公网数据完全物理隔离，无论公网发生多大规模的网络风暴，专线内部的数据包始终畅通无阻，丢包率恒定为 0.0%。

## 四、 科学上网安全事件应急响应与止损 SOP

当怀疑自己使用的代理服务出现安全异动或跑路征兆时，请立即执行以下应急处置步骤：
1. **停止一切大额资金注入**：立即取消任何代扣授权，关闭自动续费开关；
2. **导出并隔离订阅链接**：将客户端内的有效节点导出为文本文件作为备用，切忌在不受信的公共在线转换网站中粘贴此链接；

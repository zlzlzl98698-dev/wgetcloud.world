## 一、 专线架构与网络底层通识

### Q1: 什么是 IEPL 物理专线？它和普通公网中转有什么本质区别？
**答：** IEPL（International Ethernet Private Line，国际以太网专线）走的是跨国电信运营商内部铺设的点对点封闭式海底/陆地物理光纤。
- **物理机制**：端到端完全不经过公网国际出口路由器，**零 GFW 审查、零晚高峰公网拥堵，全天丢包率恒定为 0.00%**；
- **普通中转的局限**：普通中转仅是在国内服务器（如广州/上海）做数据端口转发，出境依然要走电信 163 骨干网公网出口，晚高峰拥堵丢包率高达 25%~40%。代表标杆：[光速云](/brands/lightspeed-cloud) 全线部署双专线冗余架构。

### Q2: 什么是 IPLC 专线？它和 IEPL 哪个更好？
**答：** IPLC 是最底层的物理层（L1/SDH）刚性电路，两端设备如同用一根物理光纤直连，网络单向抖动低于 1ms，单价最昂贵，是跨国金融证券高频交易与职业外服电竞的首选（如 [Firefly](/brands/firefly-accelerator)）；而 IEPL 属于数据链路层（L2）以太网专线，兼具突发带宽大与性价比高的优势，是 99% 日常 4K 追剧与 AI 生产力的最佳平衡选择。

### Q3: 为什么同一家机场在不同宽带下速度差异巨大？
**答：** 这是因为国内三大家宽运营商（电信/联通/移动）与机场国内入口服务器之间存在互联互通壁垒。若机场仅部署单线电信机房入口，移动或联通宽带用户访问时必须经过跨网互联交换点，产生 30ms~60ms 的跨网延迟与 QoS 降权。选型时务必认准具备 **“BGP 多线智能调度入口”** 的服务商。

### Q4: 什么是 BGP 边界网关协议？
**答：** BGP（Border Gateway Protocol）允许机场入口服务器同时接入电信、联通、移动三网核心骨干网。无论用户使用哪家宽带，DNS 均会自动调度至同运营商的本省直连入口，并在某处机房突发断纤时秒级自动切换至备用机房，实现无感高可用容灾。

### Q5: 为什么 2026 年不推荐继续使用自建 VPS 科学上网？
**答：** 自建 VPS（如搬瓦工、Vultr）的单 IP 暴露在公网，面对 GFW 的启发式主动探测与机器学习审查，存活周期通常不足 1 个月；一旦被墙换 IP 需支付 $3~$8 美元，且晚高峰受制于运营商 163 骨干拥堵；而成熟商业专线机场（如 [光速云](/brands/lightspeed-cloud) 折后约 ¥8/月）成本更低，且有专人 24 小时运维容灾。

### Q6: 为什么 Shadowsocks 协议适合专线内部，而 Trojan 适合公网？
**答：** Shadowsocks 采用对称 AEAD 加密，CPU 算力损耗极低，在物理封闭的专线内传输能跑满千兆吞吐；而 Trojan 伪装成标准的 HTTPS 网页流量，遵循真实浏览器 TLS 指纹，在公网中转时抗审查能力最强。

### Q7: 什么是 VLESS + Reality？为什么它被称为终极抗封锁协议？
**答：** VLESS Reality 彻底消除了服务端自签 SSL 证书的特征，直接借用全球知名大厂（如 Apple、Microsoft）的合法公钥完成握手；对外部主动探测请求原样转发至真实官网，从根本上免疫了 GFW 的证书探测，且支持 XTLS 内存零拷贝，性能提升 80%。

### Q8: 什么是 Anycast 泛播技术？
**答：** 泛播是指全球多个不同物理地点的服务器同时使用同一个 IP 地址宣告路由。客户端发起的请求会自动被路由器引导至物理距离最近、网络跳数最少的服务器，大幅降低首字节连接时间（TTFB）。

## 二、 客户端配置与跨平台排错

### Q9: 2026 年 Windows 平台首选哪款客户端？
**答：** 首选 **Clash Verge Rev**（基于 Rust + Tauri 架构与 Mihomo 内核，内存常驻仅 60MB~90MB，自带中文，支持一键 TUN 虚拟网卡）；备选极客工具为 **v2rayN** 与 **Sing-box**。

### Q10: 苹果 iPhone / iPad (iOS) 怎么下载安装小火箭 (Shadowrocket)？
**答：** 中国大陆区 App Store 下架了代理工具。必须在系统 App Store 中退出当前国区账号，登录已购买小火箭（$2.99 美元）的美区或港区 Apple ID 进行下载。**切记严禁在手机“设置”里的 iCloud 登录别人的账号！**

### Q11: 什么是 Clash 的 TUN 模式？什么时候必须开启？
**答：** 普通系统代理只能接管走系统代理 API 的浏览器流量；而 TUN 模式会在操作系统中创建一张虚拟网卡，强制接管电脑全部网络流量。在进行 **Steam/Epic 联机游戏、终端命令行编译 (git/curl/pip) 以及使用未配置代理的特定桌面软件** 时，必须开启 TUN 模式。

### Q12: 什么是 Fake-IP 模式？它和 Redir-Host 有什么区别？
**答：** Fake-IP 会为海外域名分配一个本地虚拟保留网段 IP（如 `198.18.0.1`），由客户端内核在远端服务器发起真实 DNS 解析，能彻底杜绝本地 DNS 污染并实现 0 毫秒极速解析；Redir-Host 模式则在本地先解析再转发，容易遭遇污染。

### Q13: 局域网内的 NAS、打印机在开启代理后打不开了怎么办？
**答：** 这是由于代理内核误将局域网私有网段劫持所致。在 Clash Verge Rev 设置中勾选 **“允许局域网连接”** 并开启 **“Bypass Private Network (绕过局域网网段)”**，将 `192.168.0.0/16` 与 `10.0.0.0/8` 加入直连白名单即可恢复。

### Q14: 安卓 (Android) 平台推荐哪款免费开源客户端？
**答：** 首选 **Clash Meta for Android**（完全开源免费，支持分应用代理，可让微信、支付宝直接绕过代理）；备选推荐 **NekoBox** 或 **Sing-box for Android**。

### Q15: 软路由（OpenWrt）推荐使用哪个插件做全屋代理？
**答：** 推荐 **OpenClash**（功能最全，支持策略组切换与详细日志）或 **PassWall**；拓扑建议采用“旁路由模式”，即使软路由宕机也不会影响全家正常上网。

### Q16: 订阅链接导入客户端时提示“Invalid YAML / unmarshal errors”怎么解决？
**答：** 这通常是因为机场后端数据库维护或服务器宕机，返回了一段 HTML 报错网页（如 502/504），客户端误将其当作 YAML 解析所致。请在浏览器直接访问该订阅链接，确认是否返回正常文本。

## 三、 突发网络故障与全红急救排障

### Q17: 节点列表突然全部超时全红（Timeout），如何 2 分钟内排查修复？
**答：** 按以下顺序快速处理：
1. **校准系统时间**：90% 的全红故障是由于电脑时间与网络标准授时误差超过 90 秒，导致 TLS 握手被拒；在 Windows 设置中点击“立即同步”即可恢复；
2. **释放 7890 端口**：打开任务管理器结束残留的代理进程，或运行 `taskkill /F /PID <占用PID>`；
3. **刷新本地 DNS**：在终端运行 `ipconfig /flushdns`；
4. **更换订阅节点**：登录机场官网获取最新的防封动态订阅地址。

### Q18: 为什么浏览器打不开网页，但客户端显示节点延迟只有几十毫秒？
**答：** 客户端显示的延迟仅仅代表最基础的 **TCP Ping** 成功，并不代表能够成功完成复杂的 TLS 证书握手与目标 HTTP 响应。常见原因为本地系统代理未生效，或浏览器被某些国内扩展插件恶意占用了本地代理端口。

### Q19: 提示“ERR_PROXY_CONNECTION_FAILED”是什么意思？
**答：** 表明您的操作系统开启了系统代理设置（指向 `127.0.0.1:7890`），但后台的代理软件已经意外崩溃关闭，导致浏览器向空端口发包失败。解决办法：重新启动 Clash，或者在 Windows“Internet 选项” ➔ “局域网设置”中取消勾选代理服务器。

### Q20: 为什么更新订阅时频频报错“Network Error”？
**答：** 机场的订阅分发域名遭到了当地运营商的 DNS 投毒污染。临时救急方法：先连接手机热点或连上任意一个可用旧节点，在开启系统代理的状态下点击“更新订阅”。

### Q21: 电脑连上代理后，无法登录公司内网 VPN 怎么办？
**答：** 这是由于虚拟网卡路由优先级冲突。在客户端中将公司 VPN 使用的域名（如 `*.company.internal`）和私网 IP 段配置为 `DIRECT (直连)` 策略，或者暂时关闭 TUN 模式改用系统代理模式。

### Q22: 为什么使用代理下载文件，速度会自动断流降为 0？
**答：** 这是由于廉价中转服务器的内存泄漏或网关层部署了并发连接数限制。当多线程下载（如 IDM 32 线程）打爆了服务器的连接池上限，服务器内核直接强制重置（RST）所有连接。切换为高并发承载能力的大厂专线（如 [光速云](/brands/lightspeed-cloud)）即可解决。

### Q23: 什么是 DNS 泄漏？如何检验？
**答：** DNS 泄漏是指虽然网页流量通过代理传输，但域名解析请求却依然发送给国内本地运营商 DNS，导致访问网站清单被全程记录。访问 `https://browserleaks.com/dns` 进行检验，若列表中出现中国电信/联通/移动的 DNS 服务器，即存在泄漏。

### Q24: 为什么我的电脑无法打开 192.168.1.1 路由器后台？
**答：** 开启了全局代理且未设置局域网绕过规则。在客户端策略组中确保直连规则生效，并在分流规则头部添加 `IP-CIDR,192.168.0.0/16,DIRECT`。

## 五、 节点倍率、资费计费与防扣费陷阱

### Q33: 什么是机场节点倍率？它是怎么计算扣费的？
**答：** 节点倍率是计费乘数：$$\text{实际扣除流量} = \text{真实下载数据量} \times \text{节点倍率}$$。例如通过 `2.0x` 节点下载 1GB 视频，后台账户扣除 2GB 流量；通过 `0.2x` 节点下载 1GB，仅扣除 200MB 流量。

## 六、 机场同源站群、安全隐私与防跑路

### Q41: 什么是“同源站群”？它有什么危害？
**答：** 同源站群是指同一个黑产团伙在同一套服务器主控下，换上 10~20 个不同的名字、Logo 和域名伪装成相互独立的机场。用户以为分散购买了两三家做容灾备用，实则底层全走同一套服务器；一旦上游断电或操盘手卷款，所有购买的机场会在同一秒钟全线瘫痪。

### Q42: 如何肉眼识别一家机场是否属于同源站群？

1. **测速入口 IP 相同**：解析节点域名发现两家机场的国内入口服务器属于同一个 IP 段；
2. **结账跳转商户名相同**；
3. **网站公告文案完全一致**。

### Q45: 使用机场科学上网，机场管理员能看到我的密码吗？

**答：** GFW 通过深度数据包检测（DPI）分析流量的数据包长度分布、握手熵特征，并通过主动探测机制向目标端口发送探测包。现代协议如 VLESS Reality 通过消除握手特征并借用真实大型站点证书，彻底解决了被动识别问题。

## 八、 移动端与全平台客户端进阶疑难

### Q56: iOS 小火箭 (Shadowrocket) 耗电严重、机身发热怎么解决？
**答：** 核心原因是规则列表内包含了过多的无效正则匹配，或者开启了全局 HTTPS 解密抓包。解决对策：1. 关闭“HTTPS 解密”；2. 路由模式选用“配置 (Config)”而非“代理 (Proxy)”；3. 避免订阅几十个重复的远程规则集；4. 开启 TCP Keep-Alive 与休眠节电模式。

### Q57: 为什么 Mac 开启 Clash Verge Rev 后微信或钉钉断网或无法发图？
**答：** 国内企业通讯软件（企业微信、钉钉）会检测局域网连接和本地证书。若代理软件开启了 TUN 虚拟网卡且 DNS 设置了劫持，部分内网心跳包会被错误路由。对策：在 Clash 策略组中确保 `DIRECT` 直连规则包含 `DOMAIN-SUFFIX,tencent.com` 与 `DOMAIN-SUFFIX,dingtalk.com`，并将 DNS 模式调整为 `fake-ip` 兼容模式。

### Q58: Android 设备开启代理后 Google Play 商店无法下载应用报错误代码怎么处理？
**答：** Google Play 下载时使用的是后台系统服务（com.android.providers.downloads）。如果代理客户端仅代理了前台应用，而系统下载服务走直连，会导致握手超时。对策：在 Android 客户端（如 Clash Meta for Android / Sing-box）中开启“分应用代理”并将“系统应用”一并勾选，或者直接开启 TUN 模式全局接管。

### Q59: 路由器固件 (OpenWrt / PassWall / OpenClash) 如何设置旁路由透明代理？
**答：** 旁路由架构要点：主路由负责拨号和 DHCP（网关设为主路由 IP，DNS 推荐设为旁路由 IP 或直接下发主路由）；旁路由关闭 DHCP 服务器，静态 IP 与主路由在同一网段，网关指向主路由 IP，并在防火墙开启 IP 动态伪装 (masquerading)。

### Q60: 旁路由模式下局域网投屏 (AirPlay / DLNA) 搜不到设备怎么办？
**答：** 这是因为 mDNS 组播协议（224.0.0.251 / 端口 5353）被旁路由的防火墙规则拦截或跨网段过滤。在 OpenClash 或 PassWall 中将 `224.0.0.0/4` 与 `239.0.0.0/8` 等局域网组播地址强制加入直连绕过名单，并开启 `mdns-repeater` 服务即可秒级恢复投屏。

### Q61: Windows 唤醒睡眠后代理客户端休眠报错断连如何自动恢复？
**答：** 电脑睡眠唤醒后，物理网卡重新获取 IP 需要 2~5 秒，而代理核心若在此期间尝试发起连接会抛出 `Socket Closed` 或 `No route to host`。在 Clash Verge Rev 的“高级设置”中勾选“系统唤醒后自动重启核心”，或在 TUN 模式中开启“严苛路由重置”。

### Q62: 为什么手机连接 Wi-Fi 开启代理时热点共享给电脑无法科学上网？
**答：** 手机操作系统的热点网络 (Tethering) 默认是基于物理无线网卡的 NAT 转发，不会自动流经用户层的 VPN 虚拟网卡。解决对策：1. 在手机代理软件中开启“允许局域网连接”并记下本地端口；2. 电脑连接热点后，在电脑端手动设置代理 IP 为手机局域网 IP；3. 或安卓手机已 Root 后使用 VPN-Hotspot 软件强制将热点流量重定向至 TUN 接口。

### Q63: 如何在 Linux (Ubuntu / Debian / CentOS) 服务器无头环境下运行 Clash 或 Sing-box？
**答：** 可以使用官方编译的二进制内核，配合 Systemd 服务实现开机自启。编写 `/etc/systemd/system/clash.service`，设置 `ExecStart=/usr/local/bin/clash -d /etc/clash`，并在配置文件中配置好 `mixed-port: 7890`。终端通过 `export http_proxy=http://127.0.0.1:7890` 即可让命令行具备出海能力。

### Q64: 什么是 TUN 模式？它与系统代理 (System Proxy) 有什么技术优劣？
**答：** 系统代理仅修改系统环境变量，只对遵循系统代理约定的软件（如 Chrome、Edge）生效，大量的命令行工具（cmd, bash, git）和外服游戏会直接无视系统代理从而直连超时；TUN 模式在系统底层虚拟出一块真实物理网卡，全接管所有三层 IP 数据包，无需任何应用层适配即可让任何软件强制翻墙。

### Q65: 为什么开启 TUN 模式后局域网打印机或群晖 NAS 无法访问？
**答：** TUN 虚拟网卡默认可能捕获了 `192.168.0.0/16` 或 `10.0.0.0/8` 的流量。解决办法：在客户端配置文件中的 `tun.inet4_route_exclude_address`（路由排除段）中显式添加家庭局域网私有网段（如 `192.168.1.0/24` 与 `192.168.31.0/24`），保证局域网流量直接走物理网卡路由。

## 九、 协议底层与深度抗封锁 (Shadowsocks / VLESS / Hysteria 2 / TUIC)

### Q66: 为什么 2026 年原版 Shadowsocks (SS) 直连公网会被 GFW 秒封端口？
**答：** 原版 Shadowsocks 虽然对流量载荷进行了全对称加密，但缺少握手包伪装，其产生的纯密文流在熵分析（Entropy Analysis）下具有极其鲜明的“高随机无特征”特征。GFW 的机器学习模型可在几百个包内识别并判定该连接为翻墙隧道，随即实施主动探测或阻断 IP 端口。

### Q67: 什么是 VLESS Reality 协议？为什么它不需要购买域名和配置证书？
**答：** VLESS Reality 是 Xray 团队研发的革命性伪装技术。它直接借用（偷取）互联网上合法大型网站（如 apple.com, microsoft.com, yahoo.com）的真实 TLS 证书与公钥。GFW 在进行中间人主动握手嗅探时，Reality 服务端会原封不动地将真实目标站点的 TLS 握手特征反弹给 GFW，完美通过深度包检测，且免去了节点服务端频繁申请证书的暴露风险。

### Q68: VLESS Reality 的 SNI 偷取域名如何挑选才能避免被阻断？
**答：** 偷取域名三原则：1. 必须是境外真实存在且支持 TLSv1.3 与 H2 的大型商业网站；2. 该网站国内直连访问速度快且绝对不能是被墙网站；3. 服务端落地 IP 与偷取域名目标 IP 尽量在同一国家或自治系统，避免跨大洲 TLS 延迟出现异常特征。

### Q69: 什么是 Hysteria 2 (歇斯底里) 协议？为什么它在丢包严重的恶劣网络下依然飞快？
**答：** Hysteria 2 基于标准化 QUIC 协议（UDP），自主研发了 Brutal 拥塞控制算法。传统 TCP 在遇到 5% 丢包时会主动断崖式降低发送窗口；而 Hysteria 2 根本不理会丢包率，而是通过主动测速模型按照设定速率强行下发数据，并在 UDP 丢包后毫秒级重传，极其适合晚高峰移动 4G/5G 或长途公网越洋恶劣链路。

### Q70: 什么是 TUIC 协议？它和 Hysteria 2 有什么区别？
**答：** TUIC 同样基于 QUIC 开发，其核心设计理念是“极简与低延迟”，它深度精简了握手协商层，使首包响应时间（TTFB）甚至优于直连；而 Hysteria 2 更偏向于“高吞吐与恶劣网络暴力提速”。在稳定低丢包链路中，TUIC 体验更为轻灵；在恶劣丢包网络中，Hysteria 2 速度更凶猛。

### Q71: 为什么部分国内运营商会恶意针对 UDP 流量进行 QoS 限速甚至单向丢包？
**答：** 国内部分地方运营商（特别是北方联通和广电宽带）为了限制 P2P 盗版下载与境外 UDP 隧道，会在晚高峰对公网 443 以外的 UDP 端口执行高阶 QoS 策略，丢包率可能直接飙升至 60% 以上。解决对策：将 Hysteria 2 / TUIC 端口绑定为 443（模拟 HTTPS/QUIC），或配合 UDP 伪装跳跃端口 (Port Hopping)。

### Q72: 什么是 gRPC 传输？它在代理中有何优缺点？
**答：** gRPC 是 Google 开发的基于 HTTP/2 的高性能 RPC 框架。优点是多路复用能力强、在 CDN 穿透模式下转发性能出色；缺点是底层基于严格的 TLS 状态管理，一旦链路不稳定发生断流，重连耗时略长，且对移动端 CPU 唤醒频率相对较高。

### Q73: 为什么机场即使使用了 IEPL 专线，入口协议依然推荐 Shadowsocks 或 VLESS？
**答：** 因为专线内部走的是跨境封闭物理网络，GFW 根本无法在专线内部进行嗅探阻断。因此国内入口端只需要极简、高效、CPU 消耗最低的 Shadowsocks-AEAD 或 VLESS 协议即可跑满千兆带宽，完全无需额外叠加臃肿的多重 TLS 握手伪装层。

### Q74: 什么是 WebSocket + TLS + CDN 套壳中转？为什么 2026 年基本被淘汰？
**答：** 这是 2019~2022 年间为了防止自建 VPS 被封 IP 而流行的 Cloudflare 免费 CDN 套壳方案。它的致命弱点是延迟极高（公网绕美 300ms+）、带宽被 Cloudflare 免费套餐严格限速在 5~10Mbps。在千兆光纤和 4K 蓝光流媒体普及的今天，这种高延迟低带宽方案已被主流市场淘汰。

### Q75: 什么是 Anycast BGP Anycast 入口？它如何实现智能调度与防攻击？
**答：** Anycast（任播）技术是指同一个 IP 地址在全国多个骨干网核心机房同时宣告广播。北京电信用户访问该 IP 会路由至北京机房，深圳联通用户访问则路由至广州机房。当某个区域机房遭受 DDoS 攻击或光缆切断时，BGP 路由表在毫秒级内自动将流量重定向至相邻健康机房，用户侧几乎零感知。

## 十、 账户、支付、法务安全与风控避险实战

### Q76: 科学上网被请“喝茶”的核心诱因是什么？普通网民该如何合规自保？
**答：** 法律与执法层面的高危红线只有三条：1. 私自搭建翻墙工具向公众**收费牟利**（涉嫌提供侵入、非法控制计算机信息系统程序、工具罪）；2. 在境外社交平台（X/Twitter、Telegram、YouTube）发表危害国家安全、造谣滋事的**敏感言论**；3. 参与境外暴恐、间谍或黑客活动。普通用户若仅用于**科研查阅资料、跨国外贸、外服正版游戏与合法追剧**，绝不在敏感圈子跟风评论，风险极低。

### Q77: 使用机场访问国内敏感网站或发表不当言论会被溯源吗？
**答：** **绝对会被精准溯源！** 许多商业机场为了免受牵连，会在节点后端部署严格的审计规则。更重要的是，国内网站（如贴吧、微博、知乎、微信）对境外 IP 发言执行严格的实名制手机绑定与 IP 属地公开。千万不要以为连了翻墙软件就能为所欲为。

### Q78: 机场支持微信/支付宝支付安全吗？付款记录会被倒查吗？
**答：** 绝大多数商业机场使用的是第四方聚合发卡平台或境外商户网关，账单显示通常为“某某数码商城”、“日用百货采购”或免签轮询个人收款码。公安部门办案的核心目标是追查**非法牟利的机场运营组织者**，海量普通消费者的几十元月付流水不会被逐一作为违法对象立案。但务必坚持**月付**原则，避免资金损失。

### Q79: 使用 USDT 或虚拟货币购买机场真的能实现绝对匿名吗？
**答：** 只有当你从无需 KYC 的去中心化钱包发起纯链上转账时才是匿名的；如果你是从欧易 (OKX)、币安 (Binance) 等实名认证的中心化交易所直接提币至机场收款地址，链上追踪分析系统（如 Chainalysis）依然能将该笔交易关联到你的交易所实名身份证件。

### Q80: 为什么绝对不要使用机场节点登录自己的国内银行、证券或社保 App？
**答：** 国内金融机构（招商银行、工商银行、同花顺）具备极严密的异地登录与境外 IP 风控系统。如果你挂着香港或美国 IP 登录招行 App，极易触发“异地高危盗刷预警”，导致银行卡在线支付被临时冻结，必须持身份证去线下网点柜面解冻，得不偿失。请务必在客户端规则中设置 `DIRECT` 直连中国大陆银行域名。

### Q81: 什么是 DNS 泄漏？如何验证自己的代理是否存在 DNS 泄漏？
**答：** DNS 泄漏是指虽然你的 HTTP/TCP 流量走了境外代理节点，但域名解析请求（DNS）却悄悄由本地国内运营商（如中国电信 114.114.114.114）完成，导致电信运营商完整记录下你所访问的所有境外网址。验证方法：访问 `https://browserleaks.com/dns`，如果检测出的 DNS 服务器包含中国电信/联通/移动的 IP，即存在严重 DNS 泄漏！

### Q82: 什么是 WebRTC 泄漏？浏览器如何彻底禁用 WebRTC 真实公网 IP 暴露？
**答：** WebRTC 是一项用于浏览器音视频实时通讯的技术，它具备直接向远端服务器汇报本地真实局域网 IP 和公网直连 IP 的特权，甚至能绕过普通的系统代理设置。解决对策：在 Chrome 或 Edge 浏览器中安装 `WebRTC Control` 插件并设置为“完全禁用”，或者在 Firefox 的 `about:config` 中将 `media.peerconnection.enabled` 设为 `false`。

### Q83: 购买机场订阅后如果不满意，支持退款吗？一般退款政策是什么？
**答：** 行业通行规则是：**数字虚拟商品一旦开通激活，除官方服务器遭遇不可抗力全线断网超过 72 小时外，通常不支持无理由退款**。部分良心机场提供“24小时内消耗流量小于 5GB 扣除手续费退款”条款。因此新手强烈建议先购买 **1 元体验试用包** 或最便宜的 **月付套餐**，验证满意后再续费。

### Q84: 为什么绝大多数机场严禁使用 BT / PT / P2P 下载？违规会怎样？
**答：** 商业 BitTorrent 下载会产生海量并发 UDP 连接，不仅会瞬间打满机场专线服务器的 CPU 与内存连接池，更致命的是，BT 下载往往涉及好莱坞电影与商业软件盗版，境外数据中心会向机场机房发送 DMCA 侵权投诉信，甚至导致机房直接拔线扣押服务器。绝大多数机场对 BT 行为执行**系统自动封号且不退款**。

### Q85: 遇到机场老板被抓或跑路，用户购买的剩余套餐该如何止损？
**答：** 若是通过支付宝/微信通过正规第三方商户平台（具备商户订单号）支付且时间在 7 天以内的，可在支付账单页面发起“交易投诉 - 未收到商品”，部分未被冻结的商户保证金池有机会自动退回原账户。年付用户往往血本无归，这也是我们反复强调“**坚持月付对冲**”的核心底层逻辑。

## 十一、 节点筛选、测速技巧与日常使用秘笈

### Q86: 为什么 Speedtest 测速跑满 1000Mbps，看 YouTube 还是只有 480p？
**答：** Speedtest 测速采用的是多线程瞬时突发爆破，节点只需在短短 10 秒内维持高并发即可刷出高数字；而 YouTube 4K 播放需要的是**单线程持续长连接吞吐与零丢包率**。如果节点在持续大流量下产生严重的 TCP 重传与丢包，视频播放器的缓冲池（Buffer Health）就会瞬间耗尽并自动降质。

### Q87: 什么是 Speedtest 测速作弊？不良机场是如何伪造“千兆测速图”的？
**答：** 不良机场会在国内中转服务器配置测速劫持脚本，只要探测到流量目的地为 `*.speedtest.net`，就直接将数据包在本地内网环回反射，或者走特供的短时突发带宽，给用户制造“千兆狂飙”的虚假繁荣；而一旦用户访问 YouTube、GitHub 或 Netflix，流量立刻被切换到极其廉价恶劣的公网慢线。

### Q88: 怎样用真实多线程压测（如 YouTube Stats for nerds / Fast.com）检验真实吞吐？
**答：** 最真实靠谱的验货三部曲：1. 打开 YouTube 搜索 `4K HDR 60FPS` 视频，右键开启“详细统计信息 (Stats for nerds)”，观察 `Connection Speed` 是否持续稳定在 80,000 Kbps 以上，且 `Buffer Health` 持续大于 20 秒；2. 访问 Netflix 旗下的 `Fast.com`，点击“显示更多信息”观察加载后的延迟与上传吞吐；3. 在晚高峰 20:30~22:30 执行压测，非高峰时段的测速没有任何参考价值。

### Q89: 什么是 MTR (My Traceroute)？如何用 MTR 诊断网络链路是在国内还是国外丢包？
**答：** MTR 将 Traceroute 和 Ping 合二为一，连续向目标路径上的每一个骨干网路由器发送探测包并计算丢包率。如果在国内前几跳（省内城域网到国际出口）丢包率为 0%，而一旦进入公网海底光缆（如 202.97.xxx）丢包率飙升至 30%，说明是国际出口拥堵；若专线第一跳到终点全为 0%，则为优质独立专线。

### Q90: 为什么同一节点的 Ping 值很低（如 20ms），但打开网页等待首包时间（TTFB）很长？
**答：** Ping 值低仅代表你到国内中转入口的物理 ICMP 延迟低，并不代表端到端的真实网络响应。如果中转机房到境外落地机房的转发处理性能不足、或者落地节点的 DNS 解析耗时高达 800ms、或者遭遇了 TLS 握手握手阻塞，就会导致 Ping 看着很绿但网页半天打不开的假象。

### Q91: 为什么有些机场的节点名称带有“原生”、“解非自制”、“流媒体”、“0.2x”等标记？
**答：** 这些是机场行业通行的标签属性：
* **原生 / 流媒体**：表示该节点出口拥有当地住宅或广播运营商原生 IP，支持解锁 Netflix/Disney+ 全版权；
* **解非自制**：特指可观看仅在特定地区授权的非 Netflix 官方出品剧集；
* **0.2x / 0.5x**：低倍率冷门节点，消耗 10GB 流量仅在账单中扣除 2GB~5GB，适合挂机下载；
* **3.0x / 5.0x**：高成本超大带宽专线（如专供外服电竞联机或超低延迟游戏节点）。

### Q92: 什么是“不限时流量包”？它适合什么类型的用户购买？
**答：** 常规机场套餐都有自然月到期清零的限制；“不限时流量包”（如星岛梦、光速云斯诺克 147 等）购买后流量永久有效直到消耗完毕。它极其适合：1. 平时出海需求较少、偶尔查资料或收发邮件的用户；2. 作为主力专线机场突发故障时的“第二备用应急容灾通道”。

### Q93: 如果一个月只需要几 GB 流量，该怎么买最省钱？
**答：** 方案一：购买老牌机场的“不限时轻量包”（几十元包 100G~200G 永久有效，折算下来一年只需几块钱）；方案二：选用支持按月结算的低门槛入门套餐（如 **[光速云](/brands/lightspeed-cloud)** 折后 8 元/月），既享受 IEPL 旗舰专线品质，又无需承担年付资金风险。

### Q94: 为什么合租家庭套餐比单独买多人合用更容易触发并发封禁？
**答：** 机场风控系统会监控单个订阅在同一时间对外建立连接的公网 IP 数量（即 IP 并发数）。如果几位合租室友分别处于不同的城市或使用不同的运营商网络，在同一时刻发起连接，机场系统会自动将其判定为“订阅泄露或二级贩卖”，随即自动重置订阅或封停账号 24 小时。

### Q95: 什么是机场的“设备限制”与“IP 并发限制”？
**答：** 
* **设备数限制**：指在个人中心最多可绑定的客户端数量（通常为 3~5 台）；
* **IP 并发数限制**：指同一时刻从不同外部网络接入的公网 IP 数量。通常家庭同一个 Wi-Fi 下不论连 10 台手机都只算 1 个公网 IP 并发；但一旦一台手机切到 4G，一台电脑连宽带，就算 2 个 IP 并发。

### Q96: 苹果手机和小火箭微件 (Widget) 怎么实时查看剩余流量？
**答：** 在 Shadowrocket（小火箭）的节点列表长按你的订阅名称，选择“更新”，只要机场服务端支持 `subscription-userinfo` 响应头，小火箭右上角便会自动显示 `已用 / 总量 / 到期时间`。长按 iPhone 锁屏或桌面，添加 Shadowrocket 官方微件，即可随时无需打开 App 直观监控流量余量。

### Q97: 怎么将订阅链接转换为 Base64 或 Clash 配置以防原链接被墙？
**答：** 很多机场官网提供的通用订阅链接本身没有被封锁，但用户本地网络可能对该域名有 DNS 污染。可以使用自建或信誉良好的开源订阅转换服务（如 `subconverter`），将原始订阅链接解析并转换成标准的 Clash YAML 节点文本保存在本地，彻底脱离对远程订阅 API 的实时依赖。

### Q98: 遇到重大国际会议或敏感时期，机场全线瘫痪时有什么应急自救手段？
**答：** 敏感时期自救锦囊：
